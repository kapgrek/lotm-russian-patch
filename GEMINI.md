# LOTM Russian Localization Project — AGENTS Guidelines

> **Проект:** Фанатский русификатор для игры *Lord of the Mysteries* (C7, Unreal Engine).  
> **Официальный репозиторий:** `https://github.com/kapgrek/lotm-russian-patch`

> **Архитектура:** Внешняя модификация LuaJIT через загрузчик модов. Без изменения exe-файлов и без инъекций в память.

## 📌 Ключевой манифест для агентов

Каждый агент, начинающий сессию в этом проекте, **ОБЯЗАН** первым делом:
1. Ознакомиться с правилами перевода, стилем и глоссарием в [`TRANSLATION_GUIDE.md`](file:///d:/gameDev/translate%20lotm/TRANSLATION_GUIDE.md).

**Главное правило:** Не делать повторную работу и не перезаписывать существующие качественные переводы.

## ⚠️ Критическое правило: Локализация навыков и формул (Skill Localization Standard)

1. **Двухуровневая система описания навыков в движке (Unreal Engine / Lua):**
   - Каждая способность имеет **Краткое описание** (`BriefDesc`, вкладка интерфейса «Кратко») и **Детальное описание** (`DetailDesc`, вкладка интерфейса «Подробнее»).
   - Детальные описания содержат маркеры формул динамического расчёта урона: `*d**`, `*d`, `*f`, `spellfielddisc(*id)`, `buffdisc(*id)`, `bulletdisc(*id)`, `mul(...)`.
   - Если детальный шаблон не переведён в `RuntimeTextRussian.lua`, движок `SkillBuffDescUtils:AssembleDescString` подставляет живые числа (например, 2569, 1027, 60%) в **английский шаблон**. После этого регулярки заменяют только отдельные термины, порождая «англо-русскую кашу» в интерфейсе.

2. **Запрет ограниченного сканирования:**
   - Строки боевых навыков распределены по **ВСЕМ 126 621 строкам** базы `source_en/RuntimeTextGemini.lua`. Детальные описания формул расположены в диапазоне строк **110 000 – 126 000** (например, «Пламя разума» — на строке 118 131).
   - **СТРОГО ЗАПРЕЩЕНО** использовать скрипты с лимитом чтения первых N строк файла (`candidates.Count < count` от начала). Поиск кандидатов всегда должен производиться по всему объёму базы.

3. **Обязательная автоматическая валидация:**
   - Перед завершением любой работы по боевой системе **ОБЯЗАТЕЛЬНО** запускать `tools\VerifySkillCoverage.exe`.
   - Критерий успешности: **0 пропущенных формульных описаний**.

## ⚙️ Протокол работы агента (Workflow)

1. **Проверка задач:**
   - Откройте [`TRANSLATION_LOG.md`](file:///d:/gameDev/translate%20lotm/TRANSLATION_LOG.md).
   - Определите активный пакет (батч) перевода.

2. **Процесс перевода:**
   - Перевод выполняется с английского текста из [`source_en/RuntimeTextGemini.lua`](file:///d:/gameDev/translate%20lotm/source_en/RuntimeTextGemini.lua).
   - Сохраняйте все разметки: `<InvHighlight>`, `<Mark id="...">`, `<Highlight>`, `<Note_Normal_HW>`, `<Hide>...</Hide>`, `<Tips...>`, а также токены подстановки (`%s`, `%d`, `%i`).
   - Экранируйте кавычки: `\"` внутри значений строк Lua.

3. **Синхронизация файлов и генерация шардов (КРИТИЧЕСКИ ВАЖНО):**
   - **СТРОГО ЗАПРЕЩЕНО** копировать монолитный `RuntimeTextRussian.lua` (46 МБ) в `data/RuntimeTextRussian.lua`! Это вызовет немедленный краш движка LuaJIT из-за лимита констант (`LJ_MAX_CONSTS 65536`). Файл `data/RuntimeTextRussian.lua` ОБЯЗАН оставаться легковесным стабом `return {}`.
   - При добавлении/обновлении строк в мастер-словаре `RuntimeTextRussian.lua` в корне:
     **ОБЯЗАТЕЛЬНО** перегенерируйте 1 024 шарда с помощью компилируемой утилиты:
     ```powershell
     powershell -Command "& 'C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe' /nologo /out:tools\BuildPerfectRussianShards.exe tools\BuildPerfectRussianShards.cs; .\tools\BuildPerfectRussianShards.exe"
     ```
     Утилита автоматически распределит все фразы (с двухиндексным CN+EN маппингом) по 1 024 файлам в `data/shards/` и `mod_base/Saved/Mods/lua/mods/cpdd_runtime_fixes/`.
   - При изменении `RussianLocalization.lua` в корне — скопируйте его в `data/RussianLocalization.lua` и в `mod_base/Saved/Mods/lua/mods/cpdd_runtime_fixes/RussianLocalization.lua`.
   - Если игра установлена в тестовой папке `D:\Games\...`, скопируйте обновлённые шарды и `RussianLocalization.lua` туда.

4. **Валидация:**
   - Убедитесь, что синтаксис Lua корректен (нет незакрытых кавычек, битых скобок или сломанных переносов строк).
   - Для боевых навыков запустите `tools\VerifySkillCoverage.exe` (должно быть 0 missing).

5. **Обновление дневника и отчётность:**
   - **Обязательные метрики в отчётах и дневнике:**
     Каждый отчёт пользователю и таблица в [`TRANSLATION_LOG.md`](file:///d:/gameDev/translate%20lotm/TRANSLATION_LOG.md) **ОБЯЗАНЫ** указывать:
     1. *Реально переведено уникальных строк первоисточника:* N (~X% от 126 617).
     2. *Приблизительно реально осталось перевести уникальных строк:* ~N (~Y%).
     3. *Всего записей в словаре `RuntimeTextRussian.lua`:* M (с пояснением, что на 1 фразу создаются 2 ключа CN+EN, поэтому полный словарь составит ~240 000 – 250 000 строк).
     *Запрещено* рапортовать о «100% перевода всей игры», пока реально оставшееся число уникальных строк первоисточника не достигнет 0.
   - Запишите номер пакета, дату, количество добавленных строк и краткое резюме в [`TRANSLATION_LOG.md`](file:///d:/gameDev/translate%20lotm/TRANSLATION_LOG.md).

6. **Коммит и сборка релиза:**
   - Закоммитьте изменения в Git с понятным сообщением (например, `feat(translate): batch #3 - roselle diaries and newspapers`).
   - Сборка релизного пакета выполняется **ТОЛЬКО** через:
     `powershell -ExecutionPolicy Bypass -File .\package_release.ps1 -Version "v1.X.X"`
   - Скрипт автоматически компилирует установщик со встроенным манифестом Windows 10/11, иконкой, метаданными сборки и наложением цифровой подписи Authenticode с таймстемпом DigiCert, исключая ложные срабатывания Защитника Windows.
   - Загрузка/обновление файлов релиза на GitHub выполняется через GitHub CLI:
     `gh release upload v1.X.X build/Lord-of-Mysteries-Russian-Patch.exe build/lom-russian-patch-data.zip build/release.json --clobber`

## 🛡️ Стандарт безопасности установщика (Installer & Antivirus Safety Standard)

1. **Запрет сырой сборки без манифеста и метаданных:**
   - **СТРОГО ЗАПРЕЩЕНО** компилировать `Lord-of-Mysteries-Russian-Patch.exe` через «голый» `csc.exe` без параметров `/win32manifest` и `/win32icon`. Бинарники без манифеста и метаданных сборки мгновенно блокируются эвристикой SmartScreen и Windows Defender (`Trojan:Win32/Wacatac.B!ml`).
   - При смене версии **ОБЯЗАТЕЛЬНО** синхронизировать версию в [`installer/AssemblyInfo.cs`](file:///d:/gameDev/translate%20lotm/installer/AssemblyInfo.cs) и [`installer/app.manifest`](file:///d:/gameDev/translate%20lotm/installer/app.manifest).

2. **Запрет подозрительных для эвристики конструкций:**
   - Запрещено жестко зашивать в C#-код динамические скриптовые инжекции со строками `load(source)` и `xpcall`. Все файлы загрузчика (`CPDDTranslation.lua`) должны передаваться и копироваться исключительно как готовые файлы в составе пакета данных.

3. **Обязательная проверка Защитником Windows:**
   - Перед релизом установщик проверяется локально:
     `Start-MpScan -ScanPath "build\Lord-of-Mysteries-Russian-Patch.exe" -ScanType CustomScan`
     Критерий успешности: **0 обнаруженных угроз**.
