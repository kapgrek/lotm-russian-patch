## 🏛️ Особенности Архитектуры 2.0 (Clean Architecture)

Версия 2.0 — это глобальный релиз с полной переработкой кодовой базы и шрифтового движка. Мы полностью отказались от деструктивных скриптовых костылей (отрицательный кернинг, урезание кегля, искусственные смещения виджетов) и перешли на нативный рендеринг:

1. **Физически нормализованный европейский шрифт:**
   - Горизонтальный шаг глифов (Advance Width) для всей кириллицы скорректирован на уровне контуров шрифта `Aleo_TitleNew.ttf` (~540–680 вместо моноширинного китайского 1000 CJK).
   - Текст отображается пропорционально, без огромных дыр между буквами и без сплющивания текста в интерфейсе.
2. **Распределенная архитектура шардов (1 024 файла):**
   - Перевод разбит на 1 024 независимых шарда `RuntimeTextGemini_*.lua`.
   - Двухиндексная система привязки: мгновенный доступ к переводу как по китайскому (CN), так и по английскому (EN) ключу.
   - Полная защита от аппаратных ограничений LuaJIT (`LJ_MAX_CONSTS 65536`).
3. **Zero-Latency Pre-Bake (Мгновенный отклик UI):**
   - Критические элементы интерфейса (Esc-меню, навигация, системные диалоги) предварительно прогреваются в памяти при старте игры.
   - Устранено мерцание английского текста при первом открытии окон.
4. **100% покрытие боевых формул:**
   - Все формулы расчёта урона (`*d**`, `*d`, `*f`, `spellfielddisc`, `buffdisc`) валидированы и корректно отображаются на русском языке.
5. **Канонический перевод:**
   - Все термины приведены в строгое соответствие с каноном официального русского перевода новеллы (Шут, Потусторонние, Потусторонние свойства, Метод Лицедейства, Последовательности и др.).

## 📦 Способы установки

> **ВАЖНО:** Перед установкой полностью закройте игру и её лаунчер (Bilibili / GMZZ)!

### Способ 1: Автоматический графический установщик (Рекомендуется)
1. Скачайте и запустите файл `Lord-of-Mysteries-Russian-Patch.exe` (из папки `build/` или корня репозитория).
2. Программа автоматически определит путь к установленной игре (или нажмите «Обзор...» и укажите папку `.../Game/C7`).
3. Нажмите кнопку **«Установить русификатор»**.
4. Установщик автоматически сделает резервную копию оригинальных файлов и активирует русификатор.

### Способ 2: Автономная установка в один клик (`Установить.cmd`)
1. Перейдите в папку `installer/standalone/`.
2. Запустите файл `Установить.cmd` от имени администратора.
3. Скрипт найдёт директорию игры, создаст бэкап и установит все компоненты русификатора.

## 🔄 Переключение языков и удаление

### Быстрое переключение (Русский / Английский):
- В папке `installer/standalone/` запустите скрипт `Переключить_язык.cmd` (или `Switch_Language.cmd`).
- Язык мгновенно переключится без необходимости повторной установки.

### Полное удаление мода:
- Запустите `installer/standalone/Удалить.cmd` (или удалите через графический установщик).
- Будут полностью восстановлены оригинальный шрифт, оригинальный загрузчик и очищены файлы мода.

│   ├── PatchFontAdvance.cs        # Утилита нормализации шага шрифтов
│   ├── VerifySkillCoverage.cs     # Валидатор покрытия боевых формул (100%)
│   ├── CheckOverridesCoverage.cs  # Проверка покрытия системных оверрайдов

### ⚡ Единый пайплайн перевода (`tools/LotmTranslatePipeline.exe`)
Для поддержки и обновления локализации при выходе обновлений игры используется утилита:
```powershell
# 1. Проверка текущего статуса покрытия перевода:
.\tools\LotmTranslatePipeline.exe status

# 2. Выгрузка непереведённых строк в TSV для работы переводчиков:
.\tools\LotmTranslatePipeline.exe extract 100

# 3. Применение переведённого TSV и автосборка шардов:
.\tools\LotmTranslatePipeline.exe apply tools/batch_pending.tsv
```

## 🛡️ Безопасность

- Все исполняемые файлы компилируются с официальным UAC-манифестом (`requireAdministrator`).
- Релизная сборка верифицирована антивирусом Windows Defender (0 угроз).
