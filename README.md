# Lord of the Mysteries — Русификатор (Russian Patch)

Официальный репозиторий русской локализации для игры **Lord of the Mysteries** (C7, Unreal Engine).

Проект создан на базе инъекционной архитектуры LuaJIT без модификации исполняемых файлов игры.

---

## 📥 Скачать русификатор

В разделе [**Releases**](https://github.com/kapgrek/lotm-russian-patch/releases/latest) доступны **два формата** на ваш выбор:

1. 🚀 [**Lord-of-Mysteries-Russian-Patch.exe**](https://github.com/kapgrek/lotm-russian-patch/releases/latest) — **Графический установщик (Рекомендуется)**
   * Одиночный файл, не требует распаковки архива.
   * Красивый оконный интерфейс, автоматический поиск игры, установка в один клик.
   * Встроенная кнопка мгновенного переключения языка (Русский ↔ Английский) и отката бэкапа.
2. 📦 [**lom-russian-patch-v1.32.1.zip**](https://github.com/kapgrek/lotm-russian-patch/releases/latest) — **Автономный архив с `Установить.cmd`**
   * Полностью открытый текстовый скрипт без исполняемых бинарников (0 предупреждений антивирусов).
   * Подходит для пользователей, у которых система блокирует скачивание файлов `.exe`.

## 🚀 Установка

### Вариант 1: Через графический установщик (`.exe`)
1. Закройте игру **Lord of the Mysteries**.
2. Запустите скачанный файл **`Lord-of-Mysteries-Russian-Patch.exe`**.
3. Если Windows SmartScreen покажет синее окно («Защитник Windows защитил ваш компьютер»): нажмите **«Подробнее»** ➔ **«Выполнить в любом случае»** *(это стандартное окно Microsoft для всех новых бесплатных фанатских программ без корпоративного платного сертификата за $500)*.
4. Убедитесь, что путь к игре определён корректно (папка вида `.../Game/C7`), либо нажмите **«Автопоиск»** / **«Обзор»**.
5. Нажмите кнопку **«✔ Установить / Обновить»**.
6. Запустите игру через официальный лаунчер!

### Вариант 2: Через автономный архив (`Установить.cmd` / `Install.cmd`)
1. Скачайте архив **`lom-russian-patch-v*.zip`** из [последнего релиза](https://github.com/kapgrek/lotm-russian-patch/releases/latest).
2. Распакуйте архив в любую удобную папку.
3. Запустите **`Установить.cmd`** (или **`Install.cmd`**).
4. Скрипт сам найдёт игру, создаст резервную копию оригинала и скопирует все файлы русификатора.
5. Для быстрого переключения языка используйте **`Переключить_язык.cmd`**, для удаления — **`Удалить.cmd`**.

## 🌟 Особенности

* **Автоматический установщик:** Находит игру, загружает самые актуальные пакеты перевода из GitHub Releases и активирует их в один клик.
* **Переключение языков на лету:** В окне установщика можно в любой момент переключиться между русским и английским языками без переустановки.
* **Каноничные термины:** Перевод терминов выполнен по канону официального перевода новеллы *«Повелитель Тайн»* (Шут, Провидец, Клоун, Марионетки, Нити духовного тела, Клуб Таро, Потусторонние).
* **Безопасность и совместимость:** Мод не трогает защищённые файлы игры, не использует инъекцию в оперативную память и полностью совместим с обновлениями лаунчера.

## 🛠️ Сборка установщика из исходников

Сборка установщика с манифестом Windows 10/11, иконкой и наложением цифровой подписи Authenticode:

```powershell
powershell -ExecutionPolicy Bypass -File installer/build_installer.ps1
```

Либо ручной вызов компилятора `csc.exe`:

```powershell
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /optimize+ /platform:anycpu /highentropyva+ /r:System.dll,System.Windows.Forms.dll,System.Drawing.dll,System.IO.Compression.dll,System.IO.Compression.FileSystem.dll /win32manifest:installer/app.manifest /win32icon:installer/app.ico /out:Lord-of-Mysteries-Russian-Patch.exe installer/Program.cs installer/AssemblyInfo.cs
```
