Вам доступны два способа установки:

СПОСОБ 1: АВТОНОМНЫЙ СКРИПТ (БЕЗ .EXE И БЕЗ СРАБАТЫВАНИЙ АНТИВИРУСА)
--------------------------------------------------------------------
1. Распакуйте этот ZIP-архив в любую удобную папку (или прямо в папку с игрой).
2. Запустите файл "Установить.cmd" (или "Install.cmd").
3. Скрипт автоматически найдет игру, сделает резервную копию оригинала и скопирует все файлы русификатора.
4. Запустите игру как обычно через ваш лаунчер!

Дополнительные скрипты:
- "Переключить_язык.cmd" (или "Switch_Language.cmd") — переключение между русским и английским языком в один клик.
- "Удалить.cmd" (или "Uninstall.cmd") — отключение русификатора и возврат к исходному состоянию.


СПОСОБ 2: ГРАФИЧЕСКИЙ УСТАНОВЩИК (LORD-OF-MYSTERIES-RUSSIAN-PATCH.EXE)
--------------------------------------------------------------------
Если вы скачали отдельный файл "Lord-of-Mysteries-Russian-Patch.exe":
1. Запустите его двойным кликом.
2. Если Windows SmartScreen покажет синее окно "Система Windows защитила ваш компьютер":
   нажмите ссылку "Подробнее" -> кнопку "Выполнить в любом случае".
   (Это стандартное предупреждение Windows для всех независимых фанатских программ без платного корпоративного сертификата).
3. В окне программы нажмите "✔ Установить / Обновить".
