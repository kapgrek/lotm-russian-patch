# LOTM Russian Localization Project — AGENTS Guidelines

> **Проект:** Фанатский русификатор для игры *Lord of the Mysteries* (C7, Unreal Engine).  
> **Официальный репозиторий:** `https://github.com/kapgrek/lotm-russian-patch`  
> **Базовый проект:** Английский патч Lani27 (`https://github.com/Lani27/lord-of-mysteries-english-patch`)  
> **Архитектура:** Внешняя модификация LuaJIT через загрузчик модов. Без изменения exe-файлов и без инъекций в память.

---

## 📌 Ключевой манифест для агентов

Каждый агент, начинающий сессию в этом проекте, **ОБЯЗАН** первым делом:
1. Ознакомиться с правилами перевода, стилем и глоссарием в [`TRANSLATION_GUIDE.md`](file:///d:/gameDev/translate%20lotm/TRANSLATION_GUIDE.md).
2. Прочитать журнал текущего прогресса в [`TRANSLATION_LOG.md`](file:///d:/gameDev/translate%20lotm/TRANSLATION_LOG.md).
В `TRANSLATION_LOG.md` зафиксирован текущий прогресс, сколько строк переведено, сколько осталось, и какой пакет работы является следующим.

**Главное правило:** Не делать повторную работу и не перезаписывать существующие качественные переводы.

## ⚠️ Критическое правило: Локализация навыков и формул (Skill Localization Standard)

1. **Двухуровневая система описания навыков в движке (Unreal Engine / Lua):**
   - Каждая способность имеет **Краткое описание** (`BriefDesc`, вкладка интерфейса «Кратко») и **Детальное описание** (`DetailDesc`, вкладка интерфейса «Подробнее»).
   - Детальные описания содержат маркеры формул динамического расчёта урона: `*d**`, `*d`, `*f`, `spellfielddisc(*id)`, `buffdisc(*id)`, `bulletdisc(*id)`, `mul(...)`.
   - Если детальный шаблон не переведён в `RuntimeTextRussian.lua`, движок `SkillBuffDescUtils:AssembleDescString` подставляет живые числа (например, 2569, 1027, 60%) в **английский шаблон**. После этого регулярки заменяют только отдельные термины, порождая «англо-русскую кашу» в интерфейсе.

2. **Запрет ограниченного сканирования:**
   - Строки боевых навыков распределены по **ВСЕМ 126 621 строкам** базы `source_en/RuntimeTextGemini.lua`. Детальные описания формул расположены в диапазоне строк **110 000 – 126 000** (например, «Пламя разума» — на строке 118 131).
   - **СТРОГО ЗАПРЕЩЕНО** использовать скрипты с лимитом чтения первых N строк файла (`candidates.Count < count` от начала). Поиск кандидатов всегда должен производиться по всему объёму базы.

3. **Обязательная автоматическая валидация:**
   - Перед завершением любой работы по боевой системе **ОБЯЗАТЕЛЬНО** запускать `tools\VerifySkillCoverage.exe`.
   - Критерий успешности: **0 пропущенных формульных описаний**.

## ⚙️ Протокол работы агента (Workflow)

1. **Проверка задач:**
   - Откройте [`TRANSLATION_LOG.md`](file:///d:/gameDev/translate%20lotm/TRANSLATION_LOG.md).
   - Определите активный пакет (батч) перевода.

2. **Процесс перевода:**
   - Перевод выполняется с английского текста из [`source_en/RuntimeTextGemini.lua`](file:///d:/gameDev/translate%20lotm/source_en/RuntimeTextGemini.lua).
   - Сохраняйте все разметки: `<InvHighlight>`, `<Mark id="...">`, `<Highlight>`, `<Note_Normal_HW>`, `<Hide>...</Hide>`, `<Tips...>`, а также токены подстановки (`%s`, `%d`, `%i`).
   - Экранируйте кавычки: `\"` внутри значений строк Lua.

3. **Синхронизация файлов:**
   - При обновлении `RuntimeTextRussian.lua` в корне — **ОБЯЗАТЕЛЬНО** скопируйте его в `data/RuntimeTextRussian.lua` и в тестовую установку игры:
     `D:\Games\GMZZLauncher\Game\C7\Saved\Mods\lua\mods\cpdd_runtime_fixes\RuntimeTextRussian.lua` (если игра установлена).
   - То же самое касается `RussianLocalization.lua` и `data/RussianLocalization.lua`.

4. **Валидация:**
   - Убедитесь, что синтаксис Lua корректен (нет незакрытых кавычек, битых скобок или сломанных переносов строк).
   - Для боевых навыков запустите `tools\VerifySkillCoverage.exe` (должно быть 0 missing).

5. **Обновление дневника:**
   - Пересчитайте количество переведённых строк и процент.
   - Запишите номер пакета, дату, количество добавленных строк и краткое резюме в [`TRANSLATION_LOG.md`](file:///d:/gameDev/translate%20lotm/TRANSLATION_LOG.md).

6. **Коммит и релиз:**
   - Закоммитьте изменения в Git с понятным сообщением (например, `feat(translate): batch #1 - main quests and tingen dialogues`).
   - При необходимости собрать релиз запустите:
     `.\package_release.ps1 -Version "v1.X.X"`
