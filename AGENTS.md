# LOTM Russian Localization Project — AGENTS Guidelines (Архитектура 2.0)

> **Проект:** Фанатский русификатор для игры *Lord of the Mysteries* (C7, Unreal Engine 4 / LuaJIT).  
> **Официальный репозиторий:** `https://github.com/kapgrek/lotm-russian-patch`  
> **Версия архитектуры:** 2.0.0 (Релиз Clean Architecture)  
> **Обязательно к прочтению:** Всем AI-агентам и разработчикам перед началом любых работ в репозитории.

---

## 📌 1. Ключевой манифест Архитектуры 2.0 (Clean Architecture)

В Архитектуре 2.0 проект полностью отказался от временных скриптовых костылей верстки, ломавших интерфейс игры, и устранил коренные причины проблем на уровне шрифтового движка и распределенной структуры данных.

### 🏛️ Фундаментальные принципы Архитектуры 2.0:
1. **Физическая нормализация шрифта вместо хаков верстки:**
   - Вся кириллица физически скорректирована в файле `allin_data\font\Aleo_TitleNew.ttf` (утилита `tools/PatchFontAdvance.cs`).
   - Горизонтальный шаг глифов (Horizontal Advance Width) нормализован под европейский типографический стандарт (~540–680 вместо китайского полноширинного 1000 CJK).
   - **СТРОЖАЙШИЙ ЗАПРЕТ НА ХАКИ В Lua:** Запрещены отрицательные значения `LetterSpacing = -220`, принудительное урезание кегля (`font.Size = 11..14`), сдвиги координат (`SetRenderTranslation`) и вызовы `adjustWidgetLetterSpacing`. Весь рендеринг текста в Lua выполняется нативными методами движка без искажения геометрии элементов интерфейса.

2. **Распределенная архитектура шардов (1 024 файла):**
   - Перевод хранится в 1 024 нативных шардах `data/shards/RuntimeTextGemini_*.lua`.
   - Двухиндексная система привязки: каждая фраза доступна как по китайскому (CN), так и по английскому (EN) ключу.
   - Защита от переполнения пула констант LuaJIT (`LJ_MAX_CONSTS 65536`): монолитный файл `data/RuntimeTextRussian.lua` является легковесным стабом (`return {}`, 132 байта).

3. **Zero-Latency Pre-Bake (Прогрев кэша на старте):**
   - В момент инициализации (`data/Init.lua`) критические элементы UI (Esc-меню, навигационные панели, общие кнопки) прогреваются в памяти.
   - Полностью устранено мерцание английского языка при первом открытии меню.

## 🛑 2. Золотые правила безопасности (НЕ НАРУШАТЬ)

1. **КАТЕГОРИЧЕСКИЙ ЗАПРЕТ МОДИФИКАЦИИ ИГРЫ ПОЛЬЗОВАТЕЛЯ (`D:\Games\...`):**
   - Все операции агентов производятся **ИСКЛЮЧИТЕЛЬНО** внутри рабочего каталога репозитория `D:\gameDev\NewBild\`.
   - Агенту строго запрещено копировать файлы, запускать установку или производить сканирование в папке игры пользователя. Пользователь самостоятельно устанавливает и тестирует релизы.

2. **СТАНДАРТ АНТИВИРУСНОЙ БЕЗОПАСНОСТИ И МАНИФЕСТА:**
   - Компиляция установщика `Lord-of-Mysteries-Russian-Patch.exe` выполняется строго с манифестом `installer/app.manifest`, иконкой и версионными метаданными `installer/AssemblyInfo.cs`.
   - Запрещены сырые сборки `csc.exe` без манифеста.
   - Любая сборка обязана проходить верификацию Защитником Windows (`Start-MpScan`) с результатом **0 обнаруженных угроз**.

## ⚔️ 5. Стандарт боевых навыков и формул

1. **Двухуровневое описание навыков:**
   - Краткое описание (`BriefDesc`) — общее действие.
   - Детальное описание (`DetailDesc`) — формулы расчёта урона (`*d**`, `*d`, `*f`, `spellfielddisc`, `buffdisc`, `bulletdisc`, `mul()`).
2. **Предотвращение англо-русской «каши»:**
   - Если детальный шаблон не переведён, движок подставляет значения в английский текст. Детальные шаблоны **ОБЯЗАНЫ** присутствовать в базе перевода на 100%.
3. **Обязательная валидация:**
   - Любые правки боевых текстов обязаны валидироваться через `tools\VerifySkillCoverage.exe`. Критерий: **0 missing, 100% coverage**.

## 🚀 6. Протокол релизной сборки

1. Синхронизировать номер версии во всех файлах:
   - `installer/AssemblyInfo.cs`
   - `installer/app.manifest`
   - `RussianLocalization.lua` и `data/RussianLocalization.lua`
   - `data/Init.lua`
2. Запустить скрипт сборки:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\package_release.ps1 -Version "v2.0.0"
   ```
3. Провести антивирусную проверку:
   ```powershell
   powershell -Command "Start-MpScan -ScanPath 'D:\gameDev\NewBild\build\Lord-of-Mysteries-Russian-Patch.exe' -ScanType CustomScan"
   ```
